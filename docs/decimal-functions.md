# 金額・10進数の共通関数

金額を10進文字列で入出力する。JavaScriptやRhaiの浮動小数に変換せず、stateやJSON保存にも文字列を使う。符号は任意のマイナスだけで、整数部が必須、小数点を付けた場合は1〜28桁の小数部が必須。先頭ゼロは許可。空白、プラス、指数表記、桁区切り、アンダースコア、空文字は拒否する。入力は64 UTF-8バイトまで。

[金額サンプル](../public/screens/money-lab.yaml)と[Rhai](../public/screens/money-lab.rhai)は`/pages/money-lab`で開く。単価・数量・税率を入力し、税額を1円単位で四捨五入する。これは例の丸め方であり、アプリごとの丸め単位とモードを明示する。

## APIと精度

| 関数                         | 結果                                  |
| ---------------------------- | ------------------------------------- |
| `dec_is_valid(s)`            | 有効な小数文字列かをboolで返す        |
| `dec_add(a, b)`              | 加算                                  |
| `dec_sub(a, b)`              | a−b                                   |
| `dec_mul(a, b)`              | 乗算                                  |
| `dec_div(a, b, scale, mode)` | 指定小数桁で一度だけ丸めた除算        |
| `dec_round(s, scale, mode)`  | 指定小数桁へ丸める                    |
| `dec_cmp(a, b)`              | 数値比較の-1、0、1                    |
| `dec_sum(values)`            | 小数文字列配列の合計。空配列は文字列0 |
| `num_format(s, pattern)`     | 限定書式の表示文字列                  |

計算値はrust_decimalの96ビット符号なし係数、符号、小数桁0〜28で表す。係数の上限は79228162514264337593543950335。最小の正の値は0.0000000000000000000000000001。結果は不要な末尾ゼロを除き、負のゼロは0とする。桁数を増やしたroundも表示用のゼロは追加しない。

add/sub/mulは厳密な結果を返し、表現できない結果はエラーにする。途中で精度を落とさない。sumは最後の結果だけ範囲検査し、途中の合計が上限を越えても相殺後に表現できれば成功する。配列は最大10,000要素、入力文字列の合計は65,536バイトまで。個々の計算結果は64バイト以内。型違い・0除算・範囲超過・未知の丸め方式はRhai例外。dec_is_validだけは不正な文字列にfalseを返す。

厳密な入力と最終値の検査にはrust_decimal 1.43.0を使う。途中の係数計算にはnum-bigintを使い、入力と桁数に応じた有限サイズの整数として扱う。除算は整数の商と剰余から直接指定桁へ丸め、SDKの小数除算による二重丸めを避ける。たとえば1を2.0000000000000000000000000001で割って0桁のhalf_upにすると0。

## 丸めと表示

scaleは整数0〜28。modeは以下の4種類。

| mode      | 方向                                   | -2.5を0桁 | 2.5を0桁 |
| --------- | -------------------------------------- | --------- | -------- |
| down      | ゼロ方向                               | -2        | 2        |
| up        | ゼロから離れる方向                     | -3        | 3        |
| half_up   | 最も近い値、中間値はゼロから離れる方向 | -3        | 3        |
| half_even | 最も近い値、中間値は偶数               | -2        | 2        |

upは余りがある場合だけ切り上げる。downは負の無限大へのfloorとは異なる。比較は文字列比較でなくdec_cmpを使う。

num_formatが受け付ける書式は`#,##0`、`#,##0.00`、`0.0%`、`¥#,##0`の4つだけ。表示時はhalf_upで丸め、固定桁のゼロを補う。百分率は100倍してから一度丸める。負数の通貨は`-¥1,235`、丸め後のゼロにはマイナスを付けない。出力は128バイトまで。ロケール切替・任意の書式は提供しない。

```rhai
let subtotal = dec_mul("1234.50", "2"); // "2469"
let tax = dec_round(dec_mul(subtotal, "0.10"), 0, "half_up"); // "247"
let total = dec_add(subtotal, tax); // "2716"
let label = num_format(total, "¥#,##0"); // "¥2,716"
```

時計・ブラウザimportは不要。例外をcatchせずhandlerから出した場合は、既存のstate・UI・revisionを維持する。既存APIの変更はなく、新関数を利用する配布先では対応するWASMの再配信が必要。[ライセンス通知](../THIRD_PARTY_NOTICES.md)を含める。
